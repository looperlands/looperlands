# Visual foundations

Existing: GraphicPixel for interface/body text, AdvoCut as an available display font; dark plum #1e181e / #342433, brown-plum #533642, warm foreground #e4d0b6 / #d7ab97, terracotta #b86f50 and gold #fce045. Existing panels use raster border images, sprites remain pixelated, shop cards have 6px radii, hover states brighten surfaces and transitions are approximately 0.2 seconds.

Prototype: use a 4px spacing rhythm with 8/12/16/24px group spacing. Use squared panels with small clipped corners, subtle inset borders, readable 17px message text, restrained 140ms motion and visible focus rings. Presence green always pairs with a text status. Avoid decorating every message with a bubble; group names and timestamps so chat scans easily. Gold marks selected actions. The actual game sprites and map tiles provide imagery. Use text controls and simple CSS shapes; no invented SVG or emoji navigation icons.
