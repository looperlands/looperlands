description: Source-backed pixel RPG foundations for Looperlands game interface prototypes.

Use tokens/colors_and_type.css and the bundled fonts. The existing game uses GraphicPixel and AdvoCut, plum/brown surfaces, warm text, gold highlights, sprite imagery, and pixel borders. Read README.md and brand/style-notes.md before extending this system. The source components in ui-kit-game recreate the existing composer; new social-chat controls are proposals, not existing game behavior. Preserve game readability and keep the world visible around overlays.
